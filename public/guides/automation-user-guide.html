想开始使用定时任务

在准备运行任务的这台电脑上依次完成。无需查看其他路线。

这台电脑：更新验证 → 登录 → 业务设置 → 美团与邮件检查 → 暂停任务 → 启用并核验。

开始前准备什么？

先准备好

  • 能使用 Codex 的 Mac
  • 本企业的 SMEDC 管理员账号
  • 有对应门店权限的美团账号
  • 需要邮件时，可授权的 Gmail 账号

不会写代码没有关系。提示词整段复制即可；需要登录或确认业务范围时，再按 Codex 的提示操作。

    第一步：更新并验证这台电脑的 SMEDC

    打开这台电脑的 Codex，把下面整段发送给它。它会检查核心技能、官方 launcher、当前连接和相关流程技能。

    复制整段，发给本步标明电脑的 Codex

官方流程技能：https://github.com/YinXiaoyu-1998/smedc-companion-skills

对这台电脑已安装、与所选流程有关的技能逐目录比对，区分远端本次更新、本机原有但远端漏收的通用能力和真正的企业专属配置。保留原有通用能力与业务设置；有未确认的差异时，先给我中文处理方案，等我确认后再替换。还没选流程时，不要自动安装无关的业务技能。
原任务的日程、门店、收件人和业务动作保持原安排，不启用第二套任务。正在传输或执行业务时，先核对进度再安排重连。
如果必须退出并重新打开 Codex，请明确告诉我：完成正在进行的操作后，按 Command+Q 完全退出，再重新打开并回到这段聊天发送“继续验证 SMEDC 升级”。等我操作后继续验证，不要提前宣称升级完成。
最后用中文列出：核心技能是否已更新、批准的 launcher 版本、当前 Codex 连接是否已生效、相关流程技能哪些已对齐/待选择/有待处理项，以及我下一步做什么。

  2. 使用这套流程的电脑

    第二步：登录并确认企业

    在 Codex 打开的官方 SMEDC 网页，用企业提供的管理员账号登录。没有账号时，先联系企业负责人或服务人员开通。密码和验证码只填在官方网页。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请确认这台 Mac 已完成官方 SMEDC 核心技能、MCP/launcher 的更新和实际连接验证；未完成时先带我完成。
请打开官方 SMEDC 登录页面，让我使用本企业已获授权的管理员账号登录，核对企业和当前账号角色。已有企业和业务设置直接复用，不重新创建。
登录后告诉我本机登录与权限检查结果。先不启用任务。

    看到这些才继续：Codex 明确显示已登录的企业和账号，确认是管理员；缺账号或权限时先处理缺项。

  3. 同一台电脑

    第三步：选任务，保存企业设置

    在 Codex 提供的“自动任务”网页中选择业务企业。按页面核对门店和收件人；点“预览来源设置”或“预览任务设置”，核对“变更前 / 变更后”，再点“确认本次变更”。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请读取我们企业已有的自动任务设置，缺少的再带我补齐。
用中文名称让我选择：每日数据采集、评价处理、自然周周报，以及所需门店和数据类型。请根据我已登录的美团页面提出门店对应候选，让我确认；已有分组、收件人与业务规则先展示给我。
需要自动发布回复或发邮件时，分别展示允许的门店、发件邮箱、收件人和用途，再由我确认持续授权。请打开服务返回的官方设置页面，带我预览并保存。先不要启用任务。

    看到这些才继续：页面显示已保存；门店、任务、收件人与允许的动作都正确，任务尚未启用。

    补充说明（需要时展开）

    门店对应不会改写原始报表。报表店名与授权名不一致时，让 Codex 按实际来源校正配置。管理员身份也不自动授予经营资料的读取权限。

  4. 同一台电脑

    第四步：登录美团并连接所需 Gmail

    按 Codex 打开的网页登录美团管家；评价任务还要检查经营宝。邮件任务要在 Codex 中完成 Gmail 连接授权，选择约定的发件账号。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请逐项检查这台 Mac 的运行环境，并一次只告诉我当前需要完成的一项操作：
美团任务优先检查 Codex 内置浏览器；若不可用，请接入我日常使用且已登录的 Chrome 资料，核对实际账号和企业。不要打开隔离、访客或无痕窗口代替。若接不上，请区分“浏览器连接不可用”和“美团未登录”，告诉我具体下一步。
1. 如果选择了每日入库，打开美团管家，核对已登录账号、来源企业/集团及所选门店。
2. 如果选择了评价任务，再打开经营宝，分别核对美团和点评的门店访问。
3. 如果选择了邮件交付，在 Codex 中发起 Gmail 连接授权，让我选择允许发信的 Google 账号，再核对实际发件邮箱和已发送邮件查询能力。
4. 检查下载、文件保存、所需运行组件、电脑时区和当前账号的数据权限。
请列出“已通过 / 需要我处理 / 尚未验证”的结果和下一步。无样本时明确说明文件格式待首次有数据时验证。先不要发邮件、发布回复或启用任务。

    看到这些才继续：所选任务的检查通过；仍未通过的项目有明确处理方法。只有文件样本暂缺时，必须标明首次运行还要验证格式。

    补充说明（需要时展开）

    美团登录状态不会随企业设置迁移。新电脑要检查它自己的浏览器和账号；如果日常 Chrome 已登录，让 Codex 核对是否接入同一份资料。 Gmail 网页登录成功，不等于 Codex 已连接 Gmail。无需邮件时，可以先准备本地报告。运行期间保持 Mac 开机、联网、唤醒，并保持 Codex 运行。

  5. 同一台电脑

    第五步：核对 Codex 中的暂停任务

    打开 Codex 的自动任务列表，核对 Codex 列出的任务。没有明确项目要求时，让 Codex 选择可用的本机工作方式；你不需要自己建立复杂项目。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    请为我选定的自动任务完成本机准备，并在 Codex 中创建或核对暂停任务。
请按官方清单准备所选流程的工作流技能、业务技能和运行组件；无需我手动安装 bsk。涉及美团时，请在这台电脑实际验证内置浏览器或已登录的日常 Chrome 能接入，并核对账号和企业；不可用的来源不要标为就绪。
时间只在 Codex 管理：已有任务沿用原时间、时区、模型和推理设置；没有原时间时，结合电脑通常开机的时段给我建议，等我确认。
请核对本机运行、独立运行聊天、北京时间、可用模型、工作文件夹和失败提示设置。模型不可用时给我可选项，不要自行更换。
创建后读回实际任务，向我展示每项任务的名称、时间、模型、状态及缺项。不要让我手动填写内部编号或复制旧电脑的任务文件。所有新任务先保持暂停。

    看到这些才继续：每个选定流程只有一个新任务，状态为“暂停”；时间、模型和检查结果已读回，清楚显示哪些项目还未完成。

  6. 同一台电脑

    第六步：明确启用，检查首次结果

    先确认这家企业没有其他电脑或旧任务正在执行相同流程。然后发送下面的话。

    复制下面整段，粘贴到 Codex 聊天框并发送 
    我确认：所选流程没有其他仍在执行的旧任务，刚才展示的门店、时间和允许动作已经核对。
请在准备检查通过后启用选定任务，读回实际启用状态，并按已确认的范围验证首次运行。未授权的邮件或回复保持关闭；文件格式尚未验证时，必须先验证再上传。
请分别报告下载、入库、报告、已授权邮件或回复的真实结果。不适用的项目标明“不适用”；处理中、失败和结果未知单独列出，不要记为成功或盲目重试。

    看到这些才继续：启用状态正确，首轮结果逐项清楚。若有待处理项，先按 Codex 的具体提示处理，不反复要求重传或重发。

日常运行需要我保持什么状态？

Mac 保持开机、联网与唤醒，Codex 保持运行，工作文件夹仍然可用。时间在 Codex 的自动任务中管理；门店、分组和收件人通过 SMEDC 的“自动任务”页面预览确认。需要改变这些内容时，可以直接让 Codex 带你操作。

有哪些任务可以选择？

每日数据采集：选择营业、菜品、店内已结账订单、平台外卖和收货单中的所需类型。评价处理：选择采集门店和渠道，发布范围另行确认。自然周周报：可先生成本地报告，邮件交付使用已允许的 Gmail 发件账号。三项可以分开选择。

想把这台电脑的定时任务升级到新版

    看到这些才继续：每一项变化和待决定事项都已看懂；缺失、冲突及结果不明的事项有明确处理方式。尚未确认时，不发送下一步的保存提示词。
